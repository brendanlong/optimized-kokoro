# Data provenance

- `ja_words.txt`: misaki 0.9.4's `misaki/data/ja_words.txt`, unchanged (Apache-2.0, as misaki).
  cutlet joins MeCab's words into one when their text is in it.
- `unidic.dic` (not committed; `tools/fetch_unidic.sh` writes it): UniDic 3.1.0 (2021-08-31),
  the compiled MeCab dictionary `python -m unidic download` installs for the reference
  (`https://cotonoha-dic.s3-ap-northeast-1.amazonaws.com/unidic-3.1.0.zip`, SHA-256
  `638718c4…9d59c43`), converted by `dict::build`: MeCab's double-array trie, token order,
  word costs and connection costs unchanged (context ids renumbered, see `context_order.txt`), and of each token's features only
  cutlet's reading (`pron`, else `kana`, in hiragana). UniDic is triple-licensed
  (BSD-3-Clause, GPL-2.0, LGPL-2.1); we use it under BSD-3-Clause, whose text the fetch script
  copies to `unidic.dic.LICENSE`. Copyright (c) 2011-2021, The UniDic Consortium.
- `context_order.txt`: UniDic's context ids, ordered by how often analysis of 18,366 paragraphs
  of random ja Wikipedia articles (fetched 2026-11-03 by `tools/fetch_corpus.py wiki 600`) looked
  them up (`examples/context_order.rs count`). `dict::build` renumbers the ids in that order and
  page-aligns the matrix, so the cells real text reads share pages; costs and analysis are
  unchanged. Only counts are kept, no text.
- `src/tables.rs`: generated by `tools/gen_tables.py` from misaki 0.9.4's cutlet tables (cutlet is
  MIT, by Paul O'Leary McCann; misaki's copy is Apache-2.0), jaconv's katakana table (MIT) and
  Python 3.12's Unicode 15.0 digit classes.
- The analyzer ports MeCab 0.996 (BSD-3-Clause / GPL / LGPL, Taku Kudo and NTT), the version
  fugashi 1.5.2 bundles; `num2kana.rs` ports misaki's copy of Greatdane's
  Convert-Numbers-to-Japanese (MIT).
