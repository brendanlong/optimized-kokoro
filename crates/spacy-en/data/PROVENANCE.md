# Provenance

Both data files are generated by `../export.py` from the reference venv (`reference/setup.sh`):

```sh
reference/.cache/kfa/.venv/bin/python -I crates/spacy-en/export.py crates/spacy-en/data
```

| File | Contents | Source |
|---|---|---|
| `tagger.safetensors` | `tok2vec` and `tagger` weights (float32) | en_core_web_sm 3.8.0 |
| `tokenizer.json` | prefix/suffix/infix/URL patterns, tokenizer special cases, the `lexeme_norm` table, the tag set | en_core_web_sm 3.8.0 (from spaCy's English language data) |
| | `BASE_NORMS`, the string-store symbols, `URL_PATTERN` | spaCy 3.8.5 |
| | Unicode tables for `str.isspace/isalpha/isupper/isdigit/lower` and `\w`/`\d`/`\s` | CPython 3.12.13 |

The export is deterministic; regenerating from the same packages gives byte-identical files.
